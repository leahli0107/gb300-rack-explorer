# GB300 机柜结构探索器

Leah Li 的独立 GB300 NVL72 交互式结构探索项目。

在线地址：https://leahli0107.github.io/gb300-rack-explorer/

直接点击三维模型，逐层进入机柜、计算托盘、HPM 主板和 GPU 封装。左侧部件索引与模型视图同步，包含交换托盘、网络接口、光模块及供电液冷分支。支持旋转、缩放、分解和返回。

`index.html` 为独立网页入口，Three.js 0.128.0 从 jsDelivr 加载；需联网及支持 WebGL 的浏览器。GitHub Pages 从 `main` 分支根目录发布。

模型为功能结构示意，不是原厂 CAD。价格区分转引研报估算、类别均摊和商品报价样本，来源及计价边界均显示在网页中，不应将部分小计视为整件采购报价。

本项目与 NPO 结构探索器独立维护。
